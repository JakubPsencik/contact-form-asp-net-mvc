# ASP.NET MVC Demo Application

This repository contains a simple ASP.NET MVC application designed for demonstration purposes. The application showcases the basic structure and functionality of an ASP.NET MVC project, including:

- **Controllers**: Handling user input and interactions.
- **Views**: Displaying data and user interfaces.
- **Models**: Managing data and business logic.

## Features

- Basic form validation and error handling.
- Responsive design using Bootstrap.

## Getting Started

To get started with this project, follow these steps:

1. **Clone the repository**:
    ```bash
    git clone https://github.com/JakubPsencik/contact-form-asp-net-mvc.git
    ```
2. **Navigate to the project directory**:
    ```bash
    cd contact-form-asp-net-mvc
    ```
3. **Restore the dependencies**:
    ```bash
    dotnet restore
    ```
4. **Run the application**:
    ```bash
    dotnet run
    ```

## Prerequisites

- .NET SDK 6.0 or later
- Visual Studio 2022 or any other compatible IDE
